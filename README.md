🛒 BOZORIX — Zamonaviy onlayn e'lonlar platformasi va Marketplace!

Dasturlash hamda real loyihalarga qiziquvchilar uchun Python (Django) va PostgreSQL bazasida yaratilgan BOZORIX loyihasini taqdim etamiz. 

Loyihada mahsulotlarni toifalarga ajratish, tezkor qidiruv hamda qulay savat (cart) va suhbatlar tizimi yo'lga qo'yilgan.

✨ Loyihaning asosiy imkoniyatlari:
• 📱 Moslashuvchan va zamonaviy dark-mode interfeys
• 🗂 Mahsulotlar va kategoriyalar bo'yicha saralash
• 💬 Xaridor va sotuvchi o'rtasida ichki suhbatlashuv (Chat)
• 🛒 Savatga qo'shish va e'lon joylash funksionalligi
• ☁️ Cloudinary orqali rasmlarni doimiy saqlash
